# v0.0 early beta release notes and checklist

Learn to Fly goes public as a very early beta with Modules 0 and 1 (v1.md D-26). This page
is the release record for v0.0: what is in, what is deliberately out, how to ship it and
how to add the next module.

## Scope

| Area                  | v0.0                                                                                            |
| --------------------- | ----------------------------------------------------------------------------------------------- |
| Modules               | M0 Getting started, M1 Meet the Skyhawk (`published: true`)                                     |
| Lessons               | L0.1, L0.2, L0.3, L1.1, L1.2, L1.3, L1.4 (verified, 1.8.16.0)                                   |
| Challenges            | C0.1 First flight over Livermore, C1.1 Cockpit scavenger hunt                                   |
| Reference             | V-speeds, checklists, airports, glossary, resources (all live)                                  |
| Accounts and progress | Sign up, log in, lesson progress, quiz answers, attempts, dashboard                             |
| Hidden                | Modules 2–8 (`published: false` in `content/modules.yaml`) and every draft lesson and challenge |

The hidden modules stay in the repository and in the database (the seeder unpublishes,
never deletes), so publishing one later is a content change, not a migration.

## What the beta changes in the product

- A dismissible **beta notice** above the header names the live modules and links to the
  roadmap and the issue tracker. Dismissal is remembered per version in `localStorage`.
- The **footer** shows the release ("Early beta v0.0"), read from `package.json` at build.
- The **landing page** lists the live modules from the API, then the coming ones muted,
  and uses C0.1 as its sample challenge card (it must link to a published challenge).
- The **Learn page** shows the live modules as the lesson path and a "Coming next" list.
- The **roadmap** opens with "Where we are now".
- The **dashboard** shows the course-complete badge only once all nine modules are live;
  until then finishing everything shows "All caught up".

## Release checklist (v0.0)

Run against the production URL after the deploy.

- [ ] `npm run content:validate -- --strict`, `npm run lint`, `npm run typecheck`,
      `npm test`, `npm run build` and `npm run size` pass on `main`.
- [ ] Render: `CONTENT_INCLUDE_DRAFTS` is `false`; `PUBLIC_SITE_URL` is the real URL;
      `MONGODB_URI` points at the production cluster; `SESSION_SECRET` is set.
- [ ] After the pre-deploy seed, `GET /api/v1/modules` returns exactly M0 and M1, and
      `GET /api/v1/health` reports version `0.0.0`.
- [ ] Landing page: beta notice shows; "Start lesson 0.1" opens L0.1; the sample challenge
      card opens C0.1; the curriculum list shows M0 and M1 live and M2–M8 as coming.
- [ ] Learn page: two modules, "Coming next" list below; no "being written" placeholders.
- [ ] Challenges page: two challenges; the module filter lists only M0 and M1.
- [ ] Lesson L1.4 has no "Next lesson" link; its "Fly it" opens C1.1.
- [ ] Sign up, complete L0.1, submit a C0.1 debrief, see it on the dashboard; the
      dashboard lists only M0 and M1.
- [ ] Reference pages open; the glossary and checklists load.
- [ ] Dark mode, phone width and keyboard navigation on the landing page and a lesson.
- [ ] Tag `v0.0.0`, write a GitHub Release from the CHANGELOG entry, update the README's
      production URL.

## Publishing the next module

1. Verify the module's lessons and challenges in the sim (v1.md Section 54) and set
   `published: true`, `lastVerifiedAt` and `simVersion` in each file.
2. Remove the module's `published: false` line in `content/modules.yaml`.
3. Update `LIVE_MODULES` in `src/lib/release.ts` (the beta notice and About page copy).
   The landing and Learn pages move the module from "coming" to live by themselves.
4. `npm run content:validate -- --strict`, then tick the module in v1.md Section 49.4 and
   add a "Content" entry to the CHANGELOG. Bump the patch version (`npm version patch`).

## Known gaps in v0.0

- Only two of nine modules; the course cannot be finished yet, by design.
- Challenge scoring is self-assessed (auto-grading is v1.5 on the roadmap).
- No password reset by email yet (v1.1).
- Lesson L1.4 is the last published lesson, so its "Next lesson" link is absent until
  Module 2 is published.
