# Research lanes

One agent per lane. Folder: `docs/design-kb/research/<lane-id>/`. The "leads" are starting points
recalled from memory by the orchestrator. They are NOT verified. Confirm each one before using it,
drop any you cannot confirm, and go well beyond them. Prefer sources that belong to your lane; a
work listed as a lead in another lane is that lane's to cover unless you need it for a different
finding.
